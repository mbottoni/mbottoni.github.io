Some common divergences Sep 17, 2024

Hey. usually on machine learning we have to consider distances between different probability distributions. This is in fact a hard problem and there is a misconception that the most common way to do this is using the kl divergence. I believe that this is not true.

In fact, the KL divergence is not a metric, because it is not symmetric. It have nice properties that makes it useful but there are other metrics that are more useful in specific scenarios. Sadly these metrics are not taught on introductory courses in machine learning but there is a research trend on using these metrics on common architectures where you usually use the KL divergence on the loss, suck as the VAE’s and DDPMs.

The asymmetry is easier to believe when you can move the distributions around yourself. Drag P and Q below: the two KL numbers are computed from the same pair and they disagree, while the three symmetric measures underneath do not care which distribution you call which. Try Same mean — two distributions centred identically, one narrow and one wide — and watch KL(P‖Q) and KL(Q‖P) differ by more than a nat. That gap is the whole reason the mode-seeking and mass-covering behaviours of a VAE depend on which way round you write the loss.

One family behind most of these: f-divergences #

Most of the functions above look like unrelated formulas, but KL in both directions, Jensen-Shannon, total variation, Hellinger and $\chi^2$ are all the same object with a different convex function plugged in.

Definition #

Let $P$ and $Q$ be distributions with densities (or probability mass functions) $p$ and $q$, and assume $P$ is absolutely continuous with respect to $Q$: $q(x) = 0$ implies $p(x) = 0$. Let $f : (0, \infty) \to \mathbb{R}$ be convex with $f(1) = 0$. The $f$-divergence is

$$D_f(P \,\|\, Q) = \mathbb{E}_{x \sim Q}\!\left[ f\!\left(\frac{p(x)}{q(x)}\right) \right] = \int q(x)\, f\!\left(\frac{p(x)}{q(x)}\right) dx .$$

It measures how far the likelihood ratio $p/q$ is from $1$, averaged under $Q$ and weighted by how much $f$ penalises each deviation.

The usual suspects as instances #

Divergence $f(t)$ $D_f(P \,\|\, Q)$
KL $t \log t$ $\int p \log \frac{p}{q}$
Reverse KL $-\log t$ $\int q \log \frac{q}{p}$
Pearson $\chi^2$ $(t-1)^2$ $\int \frac{(p - q)^2}{q}$
Total variation $\frac{1}{2}\lvert t - 1\rvert$ $\frac{1}{2}\int \lvert p - q \rvert$
Squared Hellinger $\frac{1}{2}(\sqrt{t} - 1)^2$ $\frac{1}{2}\int (\sqrt{p} - \sqrt{q})^2$
Jensen-Shannon $\frac{1}{2}\left[t \log t - (1 + t)\log\frac{1+t}{2}\right]$ $\frac{1}{2}\mathrm{KL}(P \,\|\, M) + \frac{1}{2}\mathrm{KL}(Q \,\|\, M)$

In the last row $M = \frac{1}{2}(P + Q)$. To check it, multiply $f(p/q)$ by $q$: $\frac{1}{2}\left[p \log\frac{p}{q} - (p+q)\log\frac{p+q}{2q}\right] = \frac{1}{2}\left[p\log\frac{p}{m} + q \log\frac{q}{m}\right]$ with $m = \frac{1}{2}(p+q)$. The Hellinger normalisation matches hellinger_distance in the code, which returns the square root of this quantity. Note that chi_squared_distance above is the symmetric chi-squared $\frac{1}{2}\sum (p-q)^2/(p+q)$, a cousin of Pearson’s $\chi^2$ and not the same number. Two more facts: swapping $P$ and $Q$ corresponds to using $t f(1/t)$ in place of $f(t)$, so a divergence is symmetric when the two agree (TV, Hellinger and JS do). And adding $c(t-1)$ to $f$ never changes $D_f$, because $\mathbb{E}_Q[p/q - 1] = 0$.

Non-negativity, from Jensen #

Since $f$ is convex, Jensen’s inequality gives

$$D_f(P \,\|\, Q) = \mathbb{E}_Q\!\left[f\!\left(\frac{p}{q}\right)\right] \ge f\!\left(\mathbb{E}_Q\!\left[\frac{p}{q}\right]\right) = f\!\left(\int q \frac{p}{q}\right) = f(1) = 0 .$$

If $f$ is strictly convex at $1$, equality holds only when $p/q$ is constant $Q$-almost everywhere, i.e. $P = Q$. So every member of the family is a valid “divergence”: non-negative and zero exactly at equality. None of them needs to be symmetric or satisfy the triangle inequality, which is my point about KL not being a metric. (TV and the square root of Hellinger are true metrics. So is the square root of JS.)

Forward vs reverse KL: covering vs seeking modes #

This is the gap you saw in the widget. Suppose $P$ is the data distribution and $Q_\theta$ is a model we fit by minimising a KL.

Forward KL, $\mathrm{KL}(P \,\|\, Q_\theta) = \mathbb{E}_P[\log p - \log q_\theta]$. The expectation is under $P$, so the cost blows up wherever $p(x) > 0$ but $q_\theta(x) \to 0$. The model is forced to put mass everywhere the data lives. If $P$ is bimodal and $Q_\theta$ is a single Gaussian, the optimum stretches across both modes and puts a lot of mass in the empty valley between them. This is mass-covering (or mean-seeking). Maximum likelihood is exactly this direction, since $\mathrm{KL}(P\,\|\,Q_\theta) = -\mathbb{E}_P[\log q_\theta] + \text{const}$.

Reverse KL, $\mathrm{KL}(Q_\theta \,\|\, P) = \mathbb{E}_{Q_\theta}[\log q_\theta - \log p]$. Now the expectation is under the model. Putting mass where $p \approx 0$ is very expensive, while ignoring a region where $p > 0$ costs nothing. The same single Gaussian now locks onto one mode and ignores the other. This is mode-seeking. Variational inference uses this direction: the gap in the ELBO of a VAE is $\mathrm{KL}(q_\phi(z \mid x) \,\|\, p(z \mid x))$. That is one reason variational posteriors tend to underestimate uncertainty.

The variational representation, and f-GAN #

Neither direction can be computed directly when all we have are samples from $P$ and $Q$, because we never get to evaluate $p/q$. The trick is convex duality. The Fenchel conjugate of $f$ is $f^*(u) = \sup_{t} \{ u t - f(t) \}$. For convex, lower semicontinuous $f$ we have $f = f^{**}$, i.e. $f(t) = \sup_u \{ u t - f^*(u) \}$. Plug that into the definition. Taking the supremum pointwise in $x$ with a function $T(x)$ in place of $u$, and noting that any particular $T$ gives a lower bound:

$$D_f(P \,\|\, Q) = \int q(x) \sup_{u}\left\{ u \frac{p(x)}{q(x)} - f^*(u) \right\} dx \;\ge\; \sup_{T} \Big( \mathbb{E}_{x \sim P}[T(x)] - \mathbb{E}_{x \sim Q}[f^*(T(x))] \Big).$$

The supremum is over functions $T$ from the sample space to the domain of $f^*$. The bound is tight, with $T^*(x) = f'\big(p(x)/q(x)\big)$, when the function class is rich enough. Both expectations on the right need only samples. For KL, $f(t) = t\log t$ gives $f^*(u) = e^{u-1}$, so

$$\mathrm{KL}(P \,\|\, Q) = \sup_T \; \mathbb{E}_P[T] - \mathbb{E}_Q\big[e^{T - 1}\big],$$

which is the Nguyen-Wainwright-Jordan estimator. f-GAN turns the bound into a game. A generator $Q_\theta$ and a critic $T_\omega$ play

$$\min_\theta \max_\omega \; \mathbb{E}_{x \sim P}[T_\omega(x)] - \mathbb{E}_{x \sim Q_\theta}[f^*(T_\omega(x))] .$$

The critic tightens the lower bound on $D_f$, and the generator pushes it down. Choosing $f$ picks the divergence the GAN minimises. The original GAN objective is the case $f(t) = t\log t - (1+t)\log(1+t)$, which equals $2\,\mathrm{JS}(P\,\|\,Q) - \log 4$.
